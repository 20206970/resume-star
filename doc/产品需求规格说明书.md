**📄 产品需求规格说明书 (PRD) 大纲：简历素材增强 Agent 插件 (MVP)**

## **1\. 项目概况 (Project Overview)**

* **产品名称：** Resume-Skill-Agent (暂定)  
* **产品类型：** 简历素材增强工具（浏览器插件/侧边栏）  
* **核心愿景：** 消除开发者“代码写得好，简历写不好”的痛点，通过 Agent 协作深度挖掘 Git 仓库价值，生成即插即用的 STAR 法则素材。

## **2\. 用户分析 (User Analysis)**

* **核心用户：** 1-5年技术经验的开发者、在校生、转行技术人员。  
* **用户痛点：**  
  * 简历描述平淡，无法体现技术深度。  
  * 项目经历与目标 JD（职位描述）匹配度低。  
  * 手动撰写 STAR 经历耗时且难以捕捉代码细节。  
* **用户偏好：** 对话式交互（Conversational UI）、技术专业感、高效且非侵入式。

## **3\. 产品架构与 Agent Skill 定义**

系统由四个核心 Agent Skill 组成，通过**对话总线**进行协作：

| 技能名称 | 职责 (Responsibility) | 核心能力 (Key Capabilities) |
| :---- | :---- | :---- |
| **JD 读心术** | 岗位画像分析 | 提取技术关键词、评估能力权重、识别企业风格。 |
| **代码考古家** | Git 资产挖掘 | 基于代码逻辑（方案A）识别高复杂度、高性能、高价值模块。 |
| **STAR 翻译官** | 文案构建与润色 | 将技术事实转化为商业/技术价值语言，支持多版本生成。 |
| **对话引导员** | 流程控制与干预 | 负责人机交互，引导用户确认关键技术点，管理上下文。 |

## **4\. 核心业务流程 (Core Business Process)**

### **4.1 典型用户路径**

1. **输入阶段：** 用户粘贴目标 JD 链接/文本，并提供 Git 仓库地址（支持 Public/Private）。  
2. **分析阶段：** Agent 协作进行“JD 洞察”与“代码结构扫描”。  
3. **干预阶段 (对话)：** \* Agent 提出潜在亮点建议。  
   * 用户通过对话选择、修改或补充细节。  
4. **生成阶段：** Agent 输出 STAR 描述块，用户一键复制到自己的简历中。

### **4.2 人机干预机制 (Human-in-the-Loop)**

* **多轮确认：** 每一个生成的 Bullet Point 必须经过用户在对话框中的“认可”或“微调”。  
* **意图理解：** 用户可以输入“更硬核一点”、“强调架构”等指令，Agent 动态调整输出。

## **5\. 功能需求清单 (Functional Requirements)**

* **\[F01\] Git 仓库智能解析：**  
  * 支持目录树扫描与关键文件筛选（AST 辅助）。  
  * 识别常见架构模式（MVC, DDD）与技术栈。  
* **\[F02\] JD 匹配度评估：**  
  * 输出岗位画像报告。  
  * 高亮代码中与岗位要求契合的部分。  
* **\[F03\] 对话式编辑器：**  
  * 支持上下文记忆的对话界面。  
  * 提供“一键润色”、“扩写/缩写”等快捷指令。  
* **\[F04\] 导出与集成：**  
  * Markdown/纯文本格式复制。  
  * (可选) 适配主流在线简历编辑平台的浮窗。

## **6\. 技术实现方案 (Technical Implementation)**

* **Prompt 策略：** 采用“三阶过滤模型”（结构扫描 \-\> 深度考古 \-\> 对话引导）。  
* **性能优化：**  
  * 代码预处理：去除 Boilerplate 代码以节省 Token。  
  * 局部读取：仅对高潜力代码块进行深度解析。  
* **数据安全与隐私：**  
  * 不存储用户原始代码，仅保留中间分析的元数据。  
  * 对话结束后支持一键清除缓存。

## **7\. 成功衡量指标 (Success Metrics)**

* **内容采用率：** 用户最终复制的素材占 AI 生成总量的比例。  
* **对话深度：** 达成一个高质量 Bullet Point 所需的平均对话轮数（目标：3 轮以内）。  
* **时间效率：** 用户产出一个完整项目亮点的时间从小时级降至分钟级。
