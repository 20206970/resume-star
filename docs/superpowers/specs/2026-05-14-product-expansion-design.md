# 产品扩展设计：Resume-Star-Skill 后续迭代

> 基于 MVP 验证后的产品扩展规划，聚焦在校生求职场景的两个方向：深化简历能力 + 延伸面试准备。

---

## 1. 前置条件

本文档描述的所有扩展，前提是现有 `resume-star` Skill 经过至少 1 次真实 JD + 真实项目的端到端验证，且以下指标达标：

- JD 解析的岗位画像准确（无关键技能遗漏）
- Bullet Point 信息密度足够、动词开头、不空泛
- 对话微调响应合理
- 中文输出不混入英文句子

验证中可能暴露的问题需先修复，再进入扩展开发。

---

## 2. 方向 A：深化简历场景

### A1: 多 JD 批量处理

**优先级：** P2

**场景：** 用户投递多个岗位，需要针对不同 JD 生成定制化的 STAR 描述，但不想每次重新扫描同一个项目。

**设计：**

- 新增 `batch` 模式：用户一次粘贴多个 JD（用 `---` 分隔），或逐个添加
- 项目扫描只做一次，结果复用给所有 JD
- 输出一份对照表：

```
## JD 批量匹配结果

### JD 1: [公司] [岗位]
- 匹配度: 高 (3/4 must-have 命中)
- 推荐亮点: B, C
- Bullet Point: ...
- 最缺技能: [X]（项目中未体现）

### JD 2: [公司] [岗位]
- 匹配度: 中 (2/4 must-have 命中)
- 推荐亮点: A, D
- Bullet Point: ...
- 最缺技能: [Y], [Z]
```

**触发方式：** 用户粘贴多条 JD 时自动识别；或用户说"我有多个岗位"。

**改动范围：** SKILL.md 新增批量模式流程分支，star-examples.md 新增批量输出格式示例。

### A2: 英文 JD / 英文输出

**优先级：** P0

**场景：** 投外企或海外岗，JD 是英文，简历也需要英文 Bullet Point。

**设计：**

- JD 解析阶段自动检测语言（中/英文），走对应的解析规则
- 英文 JD 使用英文技能关键词表解析
- Bullet Point 和 STAR 展开输出英文
- 用户可用"用英文输出"强制切换输出语言

**改动范围：**
- `jd-analysis.md` 新增英文技能关键词分类表（Hard Skills / Soft Skills / Implicit Signals）
- `star-examples.md` 新增 2-3 个英文 Bullet Point 示例 + 英文 STAR 展开示例
- SKILL.md 新增语言检测逻辑说明

### A3: 简历整体审查

**优先级：** P1

**场景：** 用户简历写完了，不确定整体质量、哪里该改。

**设计：**

- 独立流程（非三阶段，而是单次审查）
- 输入：用户粘贴整份简历 + 目标 JD
- 输出审查报告：

```
## 简历审查报告

### 整体评分: [高/中/低]
### JD 匹配度: [X/Y must-have 已覆盖]

### 结构问题
- [问题描述 + 建议]

### 弱点定位
- [最弱的部分 + 改进方向]

### 具体修改建议
- 第 X 段: [原文] → [建议修改]
- 第 Y 段: [原文] → [建议修改]

### 缺失内容
- [JD 要求但简历中未体现的技能/经历]
```

**触发方式：** 用户说"帮我看看简历""审查简历"时触发，与三阶段流程独立。

**改动范围：** SKILL.md 新增审查流程分支。

### A4: 项目经历排序建议

**优先级：** P4（建议与 A1 合并实现）

**场景：** 用户有多个项目经历，简历空间有限，不知道放哪个。

**设计：**

- 输入：多个项目路径（或已扫描的项目亮点摘要）+ 目标 JD
- 基于 JD must-have 权重，对每个项目做匹配度打分
- 输出排序建议：

```
## 项目排序建议

| 排序 | 项目 | 匹配度 | 理由 |
|------|------|--------|------|
| 1 | 项目A | 高 | 命中 3 个 must-have（Java, Spring Boot, MySQL） |
| 2 | 项目C | 中 | 命中 2 个 must-have（Python, Redis） |
| 3 | 项目B | 低 | 命中 1 个 nice-to-have（Docker） |

建议写项目A和项目C，项目B可以省略或一笔带过。
```

**触发方式：** 在 A1 批量模式中自动包含；或用户说"选哪个项目写"时单独触发。

## 3. 方向 B：面试准备延伸

### B1: 面试模拟

**优先级：** P5

**场景：** 简历写好了，但面试官追问项目细节时说不清楚。

**设计：**

- 基于已生成的 STAR 展开部分，Skill 扮演面试官进行追问
- 追问类型：
  - 技术深度：为什么选这个方案？与其他方案对比过吗？
  - 结果量化：这个数字怎么来的？有对比数据吗？
  - 替代方案：如果不用 X 你会怎么做？
  - 困难挑战：遇到最大的问题是什么？怎么解决的？
- 每轮追问后给出回答参考和改进建议
- 用户可随时输入"退出模拟"结束

**触发方式：**
- STAR 生成结束后主动提示："要不要针对这条练一下面试回答？"
- 用户说"模拟面试""练一下"时触发

**改动范围：** 新增 `resume-star/interview-sim.md` 参考文件，SKILL.md 新增模拟流程。

### B2: 技术问题预判

**优先级：** P3

**场景：** 不知道面试官会围绕目标岗位问什么技术问题。

**设计：**

- 输入：JD 岗位画像 + 项目技术栈
- 输出预测题单：

```
## 面试预测题单

### 基于 JD 要求

#### [技能1: Java] — 出现频率: 高
- [基础] Java 的垃圾回收机制了解吗？说说常见的 GC 算法。
- [中等] HashMap 的底层实现原理？Java 8 做了什么优化？
- [深入] 多线程环境下如何保证线程安全？举一个你项目中的例子。

#### [技能2: MySQL] — 出现频率: 高
- [基础] 事务的 ACID 特性是什么？
- [中等] 索引的底层数据结构？什么时候索引会失效？

### 基于你的项目

#### [项目用到的: Redis]
- 你项目中 Redis 用在什么场景？为什么选 Redis？
- Redis 的持久化机制了解吗？

### 复习优先级
1. Java 基础 + 集合框架（JD 高频 + 项目实际使用）
2. MySQL 索引和事务（JD 高频）
3. Redis 基础（项目实际使用但 JD 未要求，可能被顺带问到）
```

**触发方式：** JD 解析结束后主动提示；或用户说"会问什么""面试题"时触发。

**改动范围：** 新增 `resume-star/interview-prep.md` 参考文件。

### B3: 项目亮点口述训练

**优先级：** P6（建议与 B1 合并实现）

**场景：** 简历写得好但面试时口语表达磕巴。

**设计：**

- 把 Bullet Point 转化为口述脚本，提供两个版本：
  - 1 分钟版：项目概述（适合"介绍一下你最有成就感的项目"）
  - 3 分钟版：详细展开（适合深入追问时）
- 口述风格要求：自然口语、不用书面语、有停顿标记
- 提供口述建议：哪里该停顿、哪里该强调、哪里容易跑题
- 常见口语化问题提醒（避免"然后...然后..."、"就是...就是说..."）

**触发方式：** 与 B1 面试模拟配合使用；或用户说"怎么说这个项目"时单独触发。

**改动范围：** 在 B1 的 `interview-sim.md` 中增加口述脚本模板。

## 4. 优先级与依赖关系

### 实现顺序

```
P0: A2 英文支持
    ↓
P1: A3 简历整体审查
    ↓
P2: A1 多 JD 批量处理
  └── P4: A4 项目排序建议（合并实现）
    ↓
P3: B2 技术问题预判
    ↓
P5: B1 面试模拟
  └── P6: B3 口述训练（合并实现）
```

### 模块依赖

- A4 合并到 A1：项目排序是批量处理的自然附加输出
- B3 合并到 B1：口述脚本是面试模拟的前置准备
- A2 无依赖：纯增量改动，可最先实现
- A3 无依赖：独立流程分支
- B2 依赖 JD 解析结果：在 A2 之后做可以同时支持中英文题单

### 每个模块的改动范围

| 模块 | 新增文件 | 修改文件 |
|------|---------|---------|
| A2 英文支持 | — | jd-analysis.md, star-examples.md, SKILL.md |
| A3 简历审查 | — | SKILL.md |
| A1 批量处理 | — | SKILL.md, star-examples.md |
| A4 项目排序 | — | （合并到 A1） |
| B2 技术预判 | interview-prep.md | SKILL.md |
| B1 面试模拟 | interview-sim.md | SKILL.md |
| B3 口述训练 | — | （合并到 B1） |
